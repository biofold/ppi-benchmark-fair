Project Overview

This project implements comprehensive FAIRification of the ELIXIR 3D-BioInfo Benchmark for Protein–Protein Interfaces, transforming the original dataset into a FAIR-compliant, machine learning-ready resource with enhanced metadata and interoperability features.

Dataset FAIRification

Converted 1,677 protein interfaces with structured Bioschemas metadata, including Schema.org, EDAM, and Gene Ontology annotations.

  • 844 physiological interfaces
  • 833 non-physiological interfaces
  • 1,673 unique PDB structures

ML Readiness

Implemented MLCommons Croissant 1.0 standard for machine learning interoperability with pre-computed features and cluster-based splits.

  • Croissant JSON-LD format
  • Stratified training splits
  • 50+ structural features

FAIR Evaluation

Comprehensive FAIR assessment comparing multiple repositories with detailed improvement roadmap to achieve 100/100 FAIR score.

  • Findable: 85/100
  • Accessible: 80/100
  • Interoperable: 90/100
  • Reusable: 95/100

FAIRification Process

Metadata Architecture

Created a Bioschemas-compliant metadata framework where:

  • Dataset represents the complete PPI benchmark collection
  • DataCatalogItem represents individual protein interfaces
  • Protein (Bioschemas) represents individual protein chains
  • All entities are linked with rich annotations from EDAM, GO, and Pfam

MLCommons Croissant Integration

The dataset is packaged using the MLCommons Croissant 1.0 standard for seamless integration with machine learning pipelines:

Croissant Features:

  • Automatic Data Loading: Standardized format for ML frameworks
  • Resource Definitions: Clear specification of files and distributions
  • Record Sets: Structured interface data with features and labels
  • Metadata Extensions: Custom properties for bioinformatics features
  • Version Control: Tracked changes and updates

Machine Learning Experiments

Basic ML models were trained on pre-calculated features to validate the dataset's utility:

  • Random Forest classifier with 50+ structural features
  • Cluster-based cross-validation to prevent data leakage
  • Feature importance analysis for biological interpretation
  • Performance comparison across different splits

Getting Started

Quick Usage

# Clone repository with Git LFS
git lfs clone https://github.com/biofold/ppi-benchmark-fair.git
cd ppi-benchmark-fair

# Generate FAIR metadata
python scripts/ppi_benchmark_fair.py --fetch-pdb-metadata --output bioschema

# Run ML experiments
python scripts/ml_experiments.py --config configs/ml_basic.yaml
