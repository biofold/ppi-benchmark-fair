Overview

This repository provides FAIR-compliant metadata for the ELIXIR 3D-BioInfo Benchmark for Protein–Protein Interfaces – a dataset comprising 1,677 protein structure interfaces with 844 physiological and 833 non-physiological homodimer interfaces for machine learning and structural bioinformatics applications.

The ppi_benchmark_fair.py script generates machine-readable JSON-LD metadata compliant with multiple standards:

Quick Start

# Clone repository
git lfs clone https://github.com/biofold/ppi-benchmark-fair.git
cd ppi-benchmark-fair

# Install requirements
pip install -r requirements.txt

# Generate basic metadata
python ppi_benchmark_fair.py --output bioschema

# Generate enriched metadata (recommended)
python scripts/ppi_benchmark_fair.py \
  --fetch-pdb-metadata \
  --check-pdb-label \
  --cluster data/ppi_benchmark_seqs.clust_25_05 \
  --output bioschema \
  --verbose

Machine Learning Pipeline

ppi_ml_croissant.py provides an end-to-end machine learning pipeline for protein-protein interaction classification:

FAIR Data Loading

Loads Croissant-formatted JSON-LD metadata from local directories or GitHub repositories

Structural Feature Extraction

Extracts interface features from PDB/mmCIF files (residues within 10Å distance)

Advanced ML Pipeline

GroupKFold cross-validation, feature evaluation, and multiple ML models

Key Features:

  • Cluster-Aware Validation: GroupKFold CV ensures all interfaces from the same sequence cluster stay together
  • Structural Biology Integration: Extracts interface residues within 10Å using BioPython
  • Case Sensitivity Handling: Automatically handles uppercase/lowercase PDB file names
  • Gzipped File Support: Works directly with .pdb.gz and .cif.gz files
  • Comprehensive Feature Evaluation: ANOVA, mutual information, PCA, correlation analysis
  • Multiple ML Models: Random Forest, SVM, Logistic Regression with hyperparameter tuning
  • Visualization Suite: ROC curves, confusion matrices, feature importance plots

Quick ML Usage

# Basic usage with local dataset
python ppi_ml_croissant.py --local ./bioschemas_output

# With structural feature extraction (mmCIF format)
python ppi_ml_croissant.py --local ./bioschemas_output --extract-pdb-features

# Quick mode (reduced output)
python ppi_ml_croissant.py --local ./bioschemas_output --quick

Sequence Clustering Information

Interfaces are clustered using BLASTClust with 90% sequence identity threshold:

# Command used for clustering
blastclust -i sequences.fasta -o clusters.txt -S 25 -L 0.5 -b F

# Result: ~1050 clusters across 1,677 interfaces

Cluster Properties in Metadata:

  • ClusterID: First InterfaceID in each BLASTClust line
  • ClusterSize: Number of interfaces in the cluster
  • ClusterMembers: List of other interfaces in same cluster
  • ClusterMethod: "BLASTClust sequence clustering"
  • ClusterMethodOptions: "-S 25 -L 0.5 -b F"
