Key Features & Innovations

MLCommons Croissant 1.0

Standardized ML dataset packaging for seamless integration with machine learning frameworks and automatic data loading.

Structural Feature Extraction

Automatic extraction of interface residues within 10Å distance from PDB/mmCIF files using BioPython.

Cluster-Aware Validation

GroupKFold cross-validation using sequence clusters to prevent data leakage and ensure realistic evaluation.

Comprehensive Evaluation

Multiple ML models (Random Forest, SVM, Logistic Regression) with detailed performance metrics and visualization.

Key Insight

Random Forest achieves the best overall performance with 82.7% accuracy and 89.8% ROC-AUC, demonstrating the effectiveness of structural features for PPI classification. The cluster-aware GroupKFold validation ensures these results are generalizable to new protein families.

Quick Start Guide

1. Get the Data

git clone https://github.com/biofold/ppi-benchmark-fair.git
cd ppi-benchmark-fair

2. FAIR Metadata

python scripts/ppi_benchmark_fair.py \
  --fetch-pdb-metadata \
  --output bioschema

3. Run ML Pipeline

python scripts/ppi_ml_croissant.py \
  --local bioschema \
  --extract-pdb-features
